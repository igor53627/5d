# Часть 12 — итог

Все условия считаны одним кодом (fl_eco3 all5): 4D 96⁴, 25 000 шагов, по 5 зёрен.

1. **Направленный отбор (e^{p0})** не сохраняется при ёмкости.
   - S > 0 только в фазе роста; на плато S = −0.028 (p = 0.013).
   - Разнообразие падает: sd 0.43 → 0.22.
   - Эффективное число линий основателей 4–6 из 12.
2. **Два ресурса с компромиссом (γ = 2)** — первый режим, где разнообразие под отбором держится и растёт на плато.
   - sd 0.60 против 0.22 при направленном отборе (p = 0.002); за плато +0.023 (p = 0.034).
   - Специалисты p0 ≈ ±1 сосуществуют, ⟨p0⟩ возвращается к 0.
   - Квадратичный S в фазе роста > 0, то есть отбор разрывающий.
   - Не значимо против нейтрального контроля по sd (p = 0.13). Явных устойчивых «видов» (кластеров) нет.
3. **Ниши.** Локальной адаптации нет: corr(p0, popt(x)) ≈ 0.
4. **Сезонность.** ⟨p0⟩ следует за оптимумом с задержкой около 1000 шагов.
5. **Контроли.** В 5D и на 128⁴ ответ на отбор подтверждён нейтральным контролем: в нейтральных прогонах Δ⟨p0⟩ = 0.00, при отборе — +0.53 и +0.61. Нейтральный прогон 128⁴ к 20 000 шагам ещё не вышел на плато. По одному зерну.
6. **Стоимость** ≈ $49.
